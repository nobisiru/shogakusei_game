# LOST CIVILIZATION - Mini Demo

企画①「LOST CIVILIZATION ―ゼロから世界をつくれ―」のブラウザ体験版です。

## 今回遊べる範囲

小さな島を探索し、資源を集めて文明LEVEL 1を目指します。

1. 木・石を集める
2. たき火を作る
3. 簡易炉を作る
4. 砂を集める
5. ガラスを作る
6. 文明LEVEL 1達成

## 操作

- PC: 矢印キー / WASD
- スマホ・タブレット: 画面下の方向ボタン、またはマップをスワイプ
- 資源のあるマスへ移動すると自動で採取
- 必要素材がそろうとCRAFTボタンが押せるようになります

## ブラウザで公開する方法

GitHub Pagesを使う場合は、Repository Settings → Pages → Deploy from a branch → `main` / `/ (root)` を選択してください。
公開後は `https://nobisiru.github.io/shogakusei_game/` で遊べます。

## 次の拡張候補

銅 → 電線 → 発電機 → 電気 → 無線通信、という文明ツリーへ拡張できます。
